What I can do for you

From a first Terraform module to a production Kubernetes platform, I cover the path from commit to running service.

Cloud infrastructure

Design, build and migrate infrastructure on AWS, Azure and Google Cloud, plus Cloudflare at the edge and Hetzner for cost-efficient compute: networking, managed databases, IAM and cost-aware architecture.

Infrastructure as Code

Reproducible environments with Terraform: reusable modules, remote state, environment promotion and drift-free changes reviewed like code.

CI/CD pipelines

Fast, reliable build and release pipelines with Jenkins, Azure DevOps and GitHub/GitLab CI: automated tests, artifacts and safe deployments.

Kubernetes & containers

Containerise applications with Docker and run them on Kubernetes: cluster setup, Helm, autoscaling and a microservices-friendly platform.

Observability

Know what your systems are doing: metrics, dashboards and alerting with Grafana and friends, so issues surface before your users notice.

Automation & Linux

Python tooling and scripting to remove toil, plus solid Linux administration, backed by a Red Hat (RHCSA) certification.

Security

Hardening cloud accounts, servers and pipelines: least-privilege IAM, secrets management, network and edge protection, vulnerability scanning in CI and security reviews of existing setups.

Android Automotive

DevOps for in-vehicle infotainment (HMI) projects on Android Automotive OS: CI pipelines for Android apps, release orchestration across build systems, build and manifest verification, and reliable release-candidate delivery.

AI-assisted internal tools

Custom internal tools built quickly with AI-assisted development: dashboards, admin panels, CLIs, release and ops tooling, and integrations your team actually needs, delivered in days instead of months.

Running AI workloads
